# UniVibe — Campus Event Management and Registration Portal

UniVibe is a simple website for discovering campus events, viewing event details, registering for events, and managing event listings.

This project was created as an academic project using HTML, CSS, and basic JavaScript.

## Features

- Browse campus events
- Search and filter events
- View event details
- Register for events and see the event fee
- Add, edit, and delete event listings
- Save event and registration data in the browser using `localStorage`
- Responsive layout for different screen sizes

## Technologies

- HTML
- CSS
- JavaScript
- Browser `localStorage`

## Project files

- `index.html` — Home page
- `events.html` — Event listing and search page
- `event-details.html` — Event details page
- `register.html` — Event registration page
- `manage.html` — Event management page
- `thanks.html` — Registration confirmation page
- `detail-career.html`, `detail-music.html`, `detail-workshop.html` — Sample event detail pages
- `style.css` — Website styling
- `script.js` — Event, search, registration, and management interactions
- `viva-guide.pdf` — Project explanation for presentation and viva

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. For more consistent `localStorage` behavior, use a simple local web server to serve the project folder.

## Data and limitations

This is a front-end learning project. Event and registration data is stored in the current browser using `localStorage`. It is not shared between users or devices. The project does not include a backend, real user accounts, or online payment processing.
